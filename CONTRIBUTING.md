# Contributing

Easiest way: [open a submission](https://github.com/osaki42/awesome-claude-mods/issues/new?template=submit-mod.yml). Or send a pull request.

## What gets in

- It's a real Claude Mod (a plugin that uses function hooks), not a plain skill, hook or MCP server.
- The repo is public, has a README and works on a current Claude Code.
- It does something useful or fun. Empty demos and forks don't count.

## Format

```
- [name](link) - What it does for you, in one plain sentence.
```

- Put it in the section that fits best.
- Say what it does for the user, not how it's built.
- No marketing words ("powerful", "revolutionary", "ultimate").
- End with a period.

Mods that stop working or go unmaintained may be removed.
